\section{Le contrat comme frontière}

La pièce centrale n'est pas une base de données : c'est un \textbf{schéma}. Le
contrat canonique est validé par Pydantic, et son intérêt est autant ce qu'il
accepte que ce qu'il \emph{refuse}.

\begin{lstlisting}[language=Python,caption={Extrait du schéma : les champs interdits sont refusés, pas ignorés.}]
class DiagnosticRecord(BaseModel):
    # ... adresse, geometrie, aleas, batiment, provenance ...
    model_config = ConfigDict(extra="forbid")   # un champ inconnu = erreur

    # Explicitement ABSENTS du contrat :
    #   niveau            -> bande D03 : display-only, hors contrat
    #   score             -> jugement fusionne, interdit (constitution 2)
    #   recommandations   -> narration IA, interdite
    #   copernicus        -> hors perimetre v1
\end{lstlisting}

\begin{invariant}
Un champ interdit ne peut pas être « ajouté discrètement » : il faut modifier le
schéma, donc passer par un amendement explicite. C'est ce qui rend la règle
tenable dans le temps — elle n'est pas une consigne d'équipe, elle est une
propriété du code.
\end{invariant}

Deux mécanismes transverses protègent l'ensemble :

\begin{itemize}
  \item \textbf{La limitation de débit} s'applique aux routes qui déclenchent une
    vraie collecte, et non aux lectures légères : les chemins sont énumérés
    exactement, ce qui évite d'attraper par préfixe les routes qui n'ont pas à
    être freinées.
  \item \textbf{Les quotas amont sont protégés côté client} : la BDNB est
    appelée sous un plafond de 120 requêtes par minute et le géocodage sous
    50 par seconde, avec une réattente unique sur un 429 explicite.
\end{itemize}

\section{Les choix d'architecture, et pourquoi}

\begin{table}[h]
\centering
\small
\begin{tabularx}{\textwidth}{@{}p{4.6cm}X@{}}
\toprule
\textbf{Choix} & \textbf{Raison} \\
\midrule
FastAPI + Pydantic & Le contrat est le livrable ; le valider à l'entrée et à la
  sortie est plus utile qu'un schéma documentaire \\
Un module par source & Une source qui tombe ne doit pas contaminer les autres, et
  un parseur par format (REST, GML 3.2) reste lisible \\
Lot \(= N \times\) unitaire & Deux moteurs divergeraient : un chiffre pour
  l'unité, un autre pour le portefeuille \\
Client HTTP dédié au WFS & Le \emph{keep-alive} du WFS Géorisques est lié à son
  backend ; le mélanger avec les appels REST produit des 404 en cascade \\
Prose validée \emph{après} génération & Aucun prompt ne garantit qu'un modèle ne
  produira pas un chiffre plausible ; la garantie est dans le validateur \\
\bottomrule
\end{tabularx}
\caption{Cinq décisions structurantes et leur justification.}
\end{table}
